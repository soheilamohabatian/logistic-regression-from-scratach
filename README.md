
# Logistic Regression from Scratch

This repository contains an implementation of Logistic Regression from scratch using Python and NumPy, alongside comparisons with Scikit-Learn.

## Overview

The notebook covers the theoretical and practical foundations of binary classification:
- From-Scratch Implementation: Built entirely using NumPy, implementing the sigmoid function, binary cross-entropy loss, gradient calculation, and gradient descent optimization.
- Dataset Exploration: Applied to custom tabular data, the Breast Cancer dataset, and synthetic non-linear datasets (e.g., make_circles).
- Scikit-Learn Benchmarks: Compares custom results with Scikit-Learn's `LogisticRegression` and `SGDClassifier`.

## Requirements

- Python 3
- NumPy
- Pandas
- Matplotlib
- Scikit-Learn
- Jupyter Notebook
